# Practical AI Engineering

Learn AI and ML by doing: every topic comes with hands-on exercises, starter code, automated tests, and worked solutions.

Focus areas: **ML fundamentals, deep learning, computer vision**, then transformers, LLMs and agents.

## How this repo works

- `phases/` — lessons, in order from math and ML basics to LLMs and agents.
- `practice/` — graded exercises. Each has a `problem.md`, a `starter.py` to fill in, `tests.py` to check your work, `hints.md`, and a reference `solution.py` with `notes.md`.
- `projects/` — larger builds.

Try the exercise first, use the hints if stuck, and open the solution last.
